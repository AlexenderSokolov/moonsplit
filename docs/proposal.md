# MoonSplit 0.1.0 申报摘要

MoonSplit 是一个面向机器学习数据集准备的 MoonBit 工具，用来解决由说话人、来源文档、患者等关联键造成的分区泄漏。它把相关样本作为完整组件处理，不拆散组件，并独立审计每个分配清单是否真的满足声明隔离规则。

与通用数据划分库相比，MoonSplit 的重点是三点：多关联键传递闭包、确定性可复现输出、以及独立审计器。它不试图判断原始媒体相似度，也不承诺“数据完全没有泄漏”；它只证明用户声明的元数据隔离规则被满足。

项目保持小而完整：JSON/JSONL 输入、组件分组、holdout/K 折分配、独立审计、稳定导出、跨 wasm-gc 与 JS 目标的真实 CLI。适合作为 MoonFlowGraph 的任务规划和 MoonTrack 的实验记录之外的第三个独立组件。
